# Aurum VPN

کلاینت VPN اندروید (و بعداً iOS) با هسته **Xray-core 26**، تم لوکس **مشکی‌طلایی** و **سفید‌سرمه‌ای**، سازنده کانفیگ رایگان کلودفلر و مدیریت توکن.

## ساخت APK بدون نصب هیچ چیز (پیشنهادی)

1. در github.com یک ریپوی جدید بسازید (Private هم مشکلی ندارد).
2. همه فایل‌های این پوشه را آپلود کنید (Add file → Upload files)، **همراه پوشه `.github`**.
3. به تب **Actions** بروید؛ بیلد خودکار شروع می‌شود (حدود ۱۰ تا ۱۵ دقیقه).
4. فایل‌های APK در بخش **Releases** ریپو آماده دانلود هستند:
   - `AurumVPN-arm64-v8a.apk` برای اکثر گوشی‌ها
   - `AurumVPN-universal.apk` اگر مطمئن نیستید

## ساخت روی کامپیوتر خودتان

```bash
flutter create --platforms=android --org com.aurum --project-name aurum_vpn .
python3 tool/patch_android.py
flutter pub get
flutter build apk --release --split-per-abi
```

## امکانات

- **پروتکل‌ها:** VLESS (Reality، XTLS-Vision، WS، gRPC، XHTTP، HTTPUpgrade، mKCP)، VMess، Trojan، Shadowsocks و SS-2022، SOCKS، Hysteria2، WireGuard/WARP، کانفیگ JSON کامل Xray
- **DNS Tunnel (XDNS):** تونل DNS داخلی Xray (نسل جدید DNSTT/Slipstream) + سازنده کانفیگ با چند ریزالور
- **کانفیگ رایگان با یک دکمه:** ۱۰ کانفیگ کلودفلر (WARP + ورکر VLESS اختصاصی روی اکانت خودتان) و ۲۰ کانفیگ از منابع عمومی؛ همه موازی، هرکدام با هسته Xray واقعاً تست و بعد خودکار ایمپورت می‌شود
- **مدیریت توکن کلودفلر:** افزودن، نمایش/پنهان، ساخت/ساخت مجدد ورکر، ProxyIP، حذف (ورکر هم از اکانت پاک می‌شود)، ورکر دستی؛ ذخیره رمزنگاری‌شده
- **ساب‌ها:** نمایش کانفیگ‌ها با نام ساب، مصرف/حجم/انقضا، به‌روزرسانی موازی، QR و کپی لینک ساب
- **ورود:** کلیپ‌بورد (با تشخیص خودکار هنگام باز شدن اپ)، QR دوربین، QR از گالری، متن/base64، JSON
- **تست:** تأخیر واقعی و پینگ TCP به‌صورت موازی، مرتب‌سازی، حذف خراب‌ها و تکراری‌ها
- حالت فقط پروکسی، اتصال خودکار به سریع‌ترین، Split-tunnel بر اساس اپ، DNS و آدرس تست دلخواه

## iOS

کد Flutter برای iOS هم قابل استفاده است، ولی VPN روی آیفون به Network Extension، اکانت Apple Developer (سالانه ۹۹ دلار) و امضای اپ نیاز دارد. وقتی آماده بودید، بخش iOS اضافه می‌شود.
